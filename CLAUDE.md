## Claude Code

- Prefer a fresh Claude Code session for each meaningful feature or fix.
- At the start of a feature session, inspect `git status`, the current branch and the relevant existing code before editing.
- Use the installed Expo plugin — its skills (start with `expo:expo-overview`) and the Expo MCP documentation tools — when they are useful.
- Do not merge to `main` without explicit user approval.
